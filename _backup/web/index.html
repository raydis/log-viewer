Engineered for Production

Everything You Need to Diagnose Laravel

Built to replace slow terminal commands and bloated third-party services with a lean, private in-house dashboard.

Single-Line Headers & Accordion

Every log record renders as a clean summary row with timestamp, severity badge, and clean message. Click to expand detailed stack traces with color-coded files and line numbers.

Newest-First Chronological Sort

No more scrolling to the bottom of 100,000 lines. The latest errors appear right at the top (`desc` order) by default, with an instant toggle for oldest-first.

64KB Reverse Seek Engine

Reads files from disk tail backwards in 64KB binary chunks. Never exhausts PHP memory (`memory_limit`) even on 50GB multi-year enterprise log files.

Instant 60 FPS Search

Debounced search synchronized with `window.requestAnimationFrame()`. Highlights matched keywords with native DOM nodes without innerHTML injection vulnerabilities.

Compressed Logs (*.log.gz)

Automatically discovers and streams rotated `.log.gz` archives with a sliding memory window. No need to extract multi-gigabyte archives to disk.

Calendar Date Picker Jump

Jump to any daily log file (e.g. `laravel-2026-11-24.log`) with one click using the compact sidebar calendar picker. Highlighted dates indicate available logs.

Live Auto-Refresh & Alerts

Zero-flicker background AJAX polling (5s, 10s, 30s). Visual toast notifications and browser tab flashing (`🔴 (X) New Error!`) when errors arrive.

Password Protection & Lockout

Standalone Bcrypt password prompt independent of database users. Automatically locks out visitors for 60 seconds after 3 failed attempts.

Panic Destroy Hotkey (Ctrl+Shift+D)

Press Ctrl+Shift+D in an emergency to instantly destroy authenticated sessions and close all open tabs across your browser via `BroadcastChannel`.

Encrypted Global Hotkey (Ctrl+Shift+X)

Open `/log-viewer` from any page in your application. Injected as heavily obfuscated bytecode stream: secret keys and URLs are 100% hidden in HTML page source.

Sensitive Data Redaction

Automatically redacts passwords, Bearer tokens, API keys, database credentials, credit cards, and `APP_KEY` as `[REDACTED]` before rendering to browser.

One-Click CSV & JSON Export

Export filtered records directly into clean JSON or RFC 4180 CSV encoded with UTF-8 BOM so stack traces and characters display seamlessly in Microsoft Excel.

Got Questions?

Frequently Asked Questions

Will this package slow down my application or consume high RAM on large logs?

No. The package uses a 64KB reverse binary tail buffer (`fseek`). It reads from the end of the file backwards and stops as soon as the requested lines (e.g. 500 lines) are satisfied. It never loads entire multi-gigabyte log files into PHP memory.

Do I need database migrations or Redis to use this plugin?

Zero database footprint. The plugin runs completely on disk without migrations, tables, models, or Redis dependencies. You can install or remove it cleanly in seconds.

Can I run this in air-gapped or offline intranet environments?

Yes, 100%. By default (`LOG_VIEWER_USE_CDN=false`), all FontAwesome icons, SVG webfonts, styles, and scripts are bundled locally inside the package. No external network requests are made.

Will anyone see my secret hotkey in browser "View Source"?

No. When `LOG_VIEWER_SHORTCUT_ENCRYPT=true` (enabled by default), the injected script is compiled into an encrypted dynamic XOR bytecode stream. Inspecting page source reveals zero plain-text URLs, trigger keys, or logout endpoints.
