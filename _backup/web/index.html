User Knowledge & Operations

Deep Dive: How to Master the Log Viewer

Everything you need to know about navigating, filtering, inspecting, and managing logs in production.

1. Single-Line Headers

Every log record is displayed as a clean summary row containing the environment badge (local.ERROR, production.INFO), exact timestamp, clean message text, and stack frame counter. Multi-line clutter is tucked away until needed.

2. Click-to-Expand Accordions

Clicking any row opens a rich diagnostics card. It pinpoints the exact trigger location (in HomeController.php on line 42), shows blue file paths and orange line numbers in the stack trace, and provides dedicated tabs for Context JSON and Raw Log text.

3. Newest-First Sorting

By default, latest logs are positioned at the very top (desc order) so you never have to scroll past 50,000 lines to find what broke 10 seconds ago. Click the sort button in the toolbar to switch to oldest-first (asc) anytime.

4. Multi-Severity Filtering

Filter logs by 9 levels: Emergency, Alert, Critical, Error, Warning, Notice, Info, Debug, and Trace. You can multi-select pills (e.g. show only ERROR + WARN) or click "ALL" to reset.

5. Calendar Date Jump

When using daily rotating log channels (e.g. laravel-2026-11-24.log), click the calendar icon in the sidebar to jump directly to the log file for any date. Days with active logs are highlighted automatically.

6. Compressed Logs (*.gz)

Rotated log files compressed as *.log.gz or *.gz are automatically discovered with a purple GZ badge. You can browse their contents directly without extracting files to disk.

7. Live Polling & Alerts

Set auto-refresh to 5s, 10s, 30s, or Manual. New entries load smoothly via background AJAX with zero page flicker. If an error arrives while in another browser tab, a toast appears and the tab title flashes: 🔴 (1) New Error!.

8. CSV & JSON Data Export

Export visible, filtered records into RFC 4180 CSV encoded with UTF-8 BOM so stack traces and special characters display perfectly in Microsoft Excel, or export into formatted JSON for external analysis.

9. Keyboard Navigation

Vim-style speed: Use j/k to move between entries, Enter to expand/collapse, c to copy, / to search, and Esc to clear.

Complete Reference Manual

Environment Variables & Examples

Comprehensive, parameter-by-parameter documentation for every setting in .env and config/raytech-log-viewer.php.

Keep Only What You Need in .env: You do not need to copy all variables into your .env file! The plugin has safe, production-tested default values built into the package. Only add the variables you want to override or customize for your project (e.g. setting LOG_VIEWER_MIDDLEWARE or enabling password protection).

1. General & Routing Settings

LOG_VIEWER_ENABLED Default: true (Boolean)

Enables or disables the log viewer interface, background polling endpoints, and download routes entirely across the application.

LOG_VIEWER_ENABLED=false # Use case: Turn off log viewer temporarily on staging/demo servers
LOG_VIEWER_ROUTE_PREFIX Default: 'log-viewer' (String)

The URI path where the log viewer dashboard is mounted. Can be customized to fit your company's URL conventions.

LOG_VIEWER_ROUTE_PREFIX="admin/system-logs" # Accessible at: https://your-domain.test/admin/system-logs
LOG_VIEWER_MIDDLEWARE Default: 'web' (Comma-separated string)

Laravel middleware protecting the route. Supports single middleware (web), multiple comma-separated middlewares (web,auth,admin), or gate authorizations (can:view-logs). Leave empty to allow public access.

LOG_VIEWER_MIDDLEWARE="web,auth,can:view-logs" # Requires user login with 'view-logs' gate permission
LOG_VIEWER_DOMAIN Default: null (String or null)

Restricts log viewer access strictly to a specific domain or dedicated subdomain.

LOG_VIEWER_DOMAIN="admin.mycompany.com" # Accessible only on admin.mycompany.com/log-viewer

2. UI Theme & Branding Settings

LOG_VIEWER_THEME Default: 'light' ('light' or 'dark')

Sets the default visual theme for initial page visits. Users can also toggle theme in real-time via the topbar sun/moon icon.

LOG_VIEWER_THEME=dark # Boots interface directly in high-contrast Dark Mode
LOG_VIEWER_PRIMARY_COLOR Default: '#1f6feb' (Hex color code)

Primary brand color applied to active toolbar buttons, active log row highlights, and navigation links.

LOG_VIEWER_PRIMARY_COLOR="#4f46e5" # Replaces primary accent with Indigo (#4f46e5)
LOG_VIEWER_TITLE Default: 'RayTech Log Viewer' (String)

HTML browser title displayed in the tab title and topbar branding header.

LOG_VIEWER_TITLE="Acme Corp — Production Diagnostics" # Customizes browser tab and header title
LOG_VIEWER_LOGO Default: 'vendor/raytech-log-viewer/img/default_logo.png'

Path or absolute URL to your custom brand logo image (also used as browser tab favicon).

LOG_VIEWER_LOGO="images/company-logo.svg" # Loads public/images/company-logo.svg
LOG_VIEWER_BACK_URL & LOG_VIEWER_BACK_URL_NAME Defaults: '/' & 'Back To Home'

Controls the topbar "Back" button destination and label text. Set LOG_VIEWER_SHOW_BACK_BUTTON=false to hide it entirely.

LOG_VIEWER_SHOW_BACK_BUTTON=true
LOG_VIEWER_BACK_URL="/admin/dashboard"
LOG_VIEWER_BACK_URL_NAME="Return to Admin"

3. Log File Discovery & Directories

LOG_VIEWER_SHOW_SERVER_LOGS & LOG_VIEWER_SCAN_SERVER_LOGS Default: false (Boolean)

When set to true, automatically scans and displays web server logs in the left sidebar: Apache (error.log, access.log), Nginx, PHP error logs (ini_get('error_log')), WAMP / Laragon / XAMPP, and MySQL logs.

LOG_VIEWER_SHOW_SERVER_LOGS=true # Discovers and adds Apache/Nginx/PHP logs into sidebar
LOG_VIEWER_DIRS Default: null (Comma-separated paths)

Register additional directories to scan for *.log and *.log.gz files.

LOG_VIEWER_DIRS="storage/logs/workers, /var/log/my-daemon" # Scans custom worker and daemon folders
LOG_VIEWER_FILES Default: null (Comma-separated files)

Register specific individual log files by relative or absolute path.

LOG_VIEWER_FILES="storage/logs/cron.log, /var/log/nginx/custom-api.log" # Directly tracks individual files in the sidebar

4. Features & User Action Controls

LOG_VIEWER_ORDER Default: 'desc' ('desc' or 'asc')

Initial sorting direction. desc puts the latest errors on top so you don't scroll. asc places oldest records first.

LOG_VIEWER_ORDER=desc # Newest logs appear on top
LOG_VIEWER_ALLOW_CLEAR Default: true (Boolean)

Enables or disables the "Clear Log" button in the toolbar. When clicked, truncates the active log file to 0 bytes with confirmation.

LOG_VIEWER_ALLOW_CLEAR=false # Protects production logs from being truncated via UI
LOG_VIEWER_ALLOW_DOWNLOAD & LOG_VIEWER_ALLOW_RAW Default: true (Boolean)

Permit or forbid downloading the raw .log / .gz file to disk and viewing raw unformatted text in a new browser tab.

LOG_VIEWER_ALLOW_DOWNLOAD=true
LOG_VIEWER_ALLOW_RAW=true
LOG_VIEWER_ALLOW_DAYS_CLEANUP Default: false (Boolean safety guard)

Safety lock allowing execution of retention cleanup command php artisan raytech-log-viewer:clear --days=30. Prevents accidental log deletion in automated pipelines.

LOG_VIEWER_ALLOW_DAYS_CLEANUP=true # Unlocks terminal purging of logs older than X days

5. Global Secret Shortcut (Hotkey)

LOG_VIEWER_SHORTCUT_ENABLED Default: false (Boolean)

Enables a secret global keyboard hotkey listener across your entire application. Developers can press the shortcut anywhere on your site to open the log viewer in a new tab without exposing any visible links to end users.

LOG_VIEWER_SHORTCUT_ENABLED=true # Press Ctrl+Shift+X on any page to open /log-viewer
LOG_VIEWER_SHORTCUT_KEY, CTRL, SHIFT, ALT Default: Ctrl + Shift + X

Customize the key combination required to open the log viewer:

LOG_VIEWER_SHORTCUT_KEY="l" # Trigger character key
LOG_VIEWER_SHORTCUT_CTRL=true # Require Ctrl (or Cmd on Mac)
LOG_VIEWER_SHORTCUT_SHIFT=true # Require Shift
LOG_VIEWER_SHORTCUT_ALT=false
LOG_VIEWER_SHORTCUT_ENCRYPT Default: true (Boolean)

When enabled, the injected hotkey script is compiled into an encrypted dynamic XOR bytecode stream. Anyone viewing "View Page Source" will find zero plain-text URLs, trigger keys, or logout endpoints.

LOG_VIEWER_SHORTCUT_ENCRYPT=true # Obfuscates and encrypts injected script bytecode

6. Security, Password Protection & Rate Limiting

LOG_VIEWER_PASSWORD_PROTECTED & LOG_VIEWER_PASSWORD Default: false

Enables a standalone password challenge screen independent of Laravel database users. Passwords are validated using Bcrypt/SHA-256 via Hash::check().

LOG_VIEWER_PASSWORD_PROTECTED=true
LOG_VIEWER_PASSWORD="$2y$10$ZfUboNTMgBUhU5kVfoWyTu8X4B4WMr7trhWrjZGnpm4u9PLiDfv2W"
# Generate custom hash: php artisan raytech-log-viewer:hash myPassword123
LOG_VIEWER_ALLOWED_IPS Default: null (Comma-separated string)

IP address whitelist. When null or empty, access is permitted to all (governed by middleware). Supports exact IPs, wildcards (192.168.1.*), and CIDR subnets (10.0.0.0/8).

LOG_VIEWER_ALLOWED_IPS="127.0.0.1, ::1, 192.168.1.*, 10.0.0.0/8" # Restricts to local machine, LAN, and corporate VPN
LOG_VIEWER_MAX_ATTEMPTS & LOCKOUT DURATION Defaults: 3 attempts & 60 seconds

Brute-force protection: visitors receive up to 3 failed attempts. On the 4th attempt, they are locked out and redirected away for 60 seconds.

LOG_VIEWER_MAX_ATTEMPTS=3
LOG_VIEWER_LOCKOUT_DURATION=60 # Lockout period in seconds
LOG_VIEWER_LOCKOUT_REDIRECT="/" # Redirect destination on lockout
LOG_VIEWER_DESTROY_SHORTCUT_KEY Default: 'd' (Ctrl + Shift + D)

Emergency panic key: pressing Ctrl+Shift+D immediately destroys the session and closes all open log viewer browser tabs via BroadcastChannel.

LOG_VIEWER_DESTROY_SHORTCUT_KEY="d" # Triggers immediate multi-tab emergency shutdown
LOG_VIEWER_REDACTION_ENABLED Default: true (Boolean)

Automatically redacts sensitive passwords, tokens, API keys, database credentials, card numbers, and APP_KEY as [REDACTED] in rendered log messages, stack traces, and context JSON.

LOG_VIEWER_REDACTION_ENABLED=true # Keeps sensitive credentials out of the browser UI

Got Questions?

Frequently Asked Questions

Will this package slow down my application or consume high RAM on large logs?

No. The package uses a 64KB reverse binary tail buffer (`fseek`). It reads from the end of the file backwards and stops as soon as the requested lines (e.g. 500 lines) are satisfied. It never loads entire multi-gigabyte log files into PHP memory.

Do I need database migrations or Redis to use this plugin?

Zero database footprint. The plugin runs completely on disk without migrations, tables, models, or Redis dependencies. You can install or remove it cleanly in seconds.

Can I run this in air-gapped or offline intranet environments?

Yes, 100%. By default (`LOG_VIEWER_USE_CDN=false`), all FontAwesome icons, SVG webfonts, styles, and scripts are bundled locally inside the package. No external network requests are made.

Will anyone see my secret hotkey in browser "View Source"?

No. When `LOG_VIEWER_SHORTCUT_ENCRYPT=true` (enabled by default), the injected script is compiled into an encrypted dynamic XOR bytecode stream. Inspecting page source reveals zero plain-text URLs, trigger keys, or logout endpoints.
